# B2.3 — Scripting du navigateur — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter au moteur navigateur trois verbes de scripting — `eval` (exécuter du JS, renvoie du JSON), `select` (choisir une option de `<select>` via un helper JS sur le nœud résolu), `addscript` (script persistant au chargement) — introduisant l'exécution de JavaScript.

**Architecture:** `eval` utilise `page.evaluate_expression` (CDP `Runtime.evaluate`, `await_promise`+`return_by_value`) et sérialise le résultat en JSON. `select` résout `ref → backend_node_id` (table B2.2) via `DOM.resolveNode` puis `Runtime.callFunctionOn` avec un helper figé. `addscript` utilise `page.evaluate_on_new_document`. Chaque verbe est une tranche verticale : `BrowserCommand` → bras `dispatch` → `ClientMessage` → handler daemon → CLI.

**Tech Stack:** Rust ; `chromiumoxide` 0.9.1 (CDP) ; le moteur `BrowserEngine`/`Session` de B2.1-B2.2 ; postcard/serde ; CLI `wimux browser`.

## Global Constraints

- **Protocole postcard positionnel** : nouvelles variantes de `ClientMessage` et de `BrowserCommand` **en FIN d'enum**. Ne jamais insérer au milieu.
- **`ref_`** est le nom du champ « référence » partout (mot-clé Rust `ref`).
- **Introduction de l'exécution JS** : c'est le périmètre de B2.3. `eval`/`addscript` exécutent du JS écrit par l'opérateur (Claude/CLI), PAS par la page. `select` utilise un helper JS figé (le nôtre) sur un nœud résolu. Le moteur reste **pur mécanisme**.
- **Sécurité (fil rouge B2)** : la sortie de `eval` peut contenir du contenu de page → donnée non fiable, imprimée telle quelle, jamais exécutée ni utilisée pour piloter le flot. Le durcissement (valve `browser-eval off`, skill) est **B2.4**, hors périmètre ici.
- **Réponses réutilisées** : `eval`/`addscript` → `BrowserReply::Text` (→ `ServerMessage::BrowserText`) ; `select` → `BrowserReply::Ok` (→ `ServerMessage::Ok`) ; erreurs → `Error`. **Aucun nouveau `ServerMessage`.**
- **Tests navigateur** : moteur headless (`BrowserEngine::new(true)`), stables et lancés en séquentiel.

### Référence API CDP vérifiée (chromiumoxide / chromiumoxide_cdp 0.9.1)

- `page.evaluate_expression(impl Into<EvaluateParams>) -> Result<EvaluationResult>`. **Renvoie `Err(CdpError::JavascriptException)` si le JS lève une exception** (vérifié dans `handler/page.rs`). `EvaluationResult::value(&self) -> Option<&serde_json::Value>`.
- `EvaluateParams` (sous `chromiumoxide::cdp::js_protocol::runtime`) : builder `.expression(impl Into<String>)`, `.return_by_value(true)`, `.await_promise(true)`, `.build() -> Result<_, String>`.
- `DOM.resolveNode` : `chromiumoxide::cdp::browser_protocol::dom::ResolveNodeParams { node_id: Option<NodeId>, backend_node_id: Option<BackendNodeId>, object_group: Option<String>, execution_context_id: Option<...> }` (struct literal ; tous `Option`). Réponse : `resp.result.object: RemoteObject`, `RemoteObject.object_id: Option<RemoteObjectId>`.
- `Runtime.callFunctionOn` : `chromiumoxide::cdp::js_protocol::runtime::CallFunctionOnParams` builder `.function_declaration(impl Into<String>)`, `.object_id(impl Into<RemoteObjectId>)`, `.argument(impl Into<CallArgument>)`, `.return_by_value(true)`, `.build() -> Result<_, String>`. Réponse : `resp.result: CallFunctionOnReturns { result: RemoteObject, exception_details: Option<ExceptionDetails> }`.
- `CallArgument` (struct, 3 champs `Option`) : `CallArgument { value: Option<serde_json::Value>, unserializable_value: None, object_id: None }`.
- `Runtime.releaseObject` : `ReleaseObjectParams::new(impl Into<RemoteObjectId>)`.
- `RemoteObjectId(String)` et `ScriptIdentifier(String)` : newtypes `Clone`, `.inner() -> &String`.
- `page.evaluate_on_new_document(impl Into<AddScriptToEvaluateOnNewDocumentParams>) -> Result<ScriptIdentifier>` (accepte une `String`).

```rust
        BrowserCommand::Select { ref_, value } => {
            use chromiumoxide::cdp::browser_protocol::dom::{BackendNodeId, ResolveNodeParams};
            use chromiumoxide::cdp::js_protocol::runtime::{
                CallArgument, CallFunctionOnParams, ReleaseObjectParams,
            };
            let s = sess
                .as_ref()
                .ok_or_else(|| "aucun navigateur : lance-le ou navigue d'abord".to_string())?;
            let bid = backend_id_for(s, &ref_)?;
            // Résoudre le nœud DOM en objet JS.
            let resolved = s
                .page
                .execute(ResolveNodeParams {
                    node_id: None,
                    backend_node_id: Some(BackendNodeId::new(bid)),
                    object_group: None,
                    execution_context_id: None,
                })
                .await
                .map_err(|e| format!("select (resolveNode) : {e}"))?;
            let oid = resolved
                .result
                .object
                .object_id
                .ok_or_else(|| "select : élément non résoluble".to_string())?;
            // Helper JS FIGÉ (le nôtre) : sélectionne par value d'option, sinon par
            // texte visible, puis émet l'événement `change`. Renvoie {ok, reason}.
            let f = "function(v){ \
                if (this.tagName !== 'SELECT') { return {ok:false, reason:'pas un <select>'}; } \
                for (const o of this.options) { if (o.value === v) { this.value = v; \
                    this.dispatchEvent(new Event('change',{bubbles:true})); return {ok:true}; } } \
                for (const o of this.options) { if (o.text === v) { this.value = o.value; \
                    this.dispatchEvent(new Event('change',{bubbles:true})); return {ok:true}; } } \
                return {ok:false, reason:'aucune option ne correspond'}; }";
            let call = CallFunctionOnParams::builder()
                .function_declaration(f)
                .object_id(oid.clone())
                .argument(CallArgument {
                    value: Some(serde_json::Value::String(value)),
                    unserializable_value: None,
                    object_id: None,
                })
                .return_by_value(true)
                .build()
                .map_err(|e| format!("select (params) : {e}"))?;
            let r = s
                .page
                .execute(call)
                .await
                .map_err(|e| format!("select (callFunctionOn) : {e}"))?;
            // Libère l'objet distant (best-effort).
            let _ = s.page.execute(ReleaseObjectParams::new(oid)).await;
            if r.result.exception_details.is_some() {
                return Err("select : exception JS pendant la sélection".into());
            }
            let val = r
                .result
                .result
                .value
                .ok_or_else(|| "select : réponse vide".to_string())?;
            if val.get("ok").and_then(|b| b.as_bool()).unwrap_or(false) {
                Ok(BrowserReply::Ok)
            } else {
                let reason = val
                    .get("reason")
                    .and_then(|s| s.as_str())
                    .unwrap_or("échec")
                    .to_string();
                Err(format!("select : {reason}"))
            }
        }
```
